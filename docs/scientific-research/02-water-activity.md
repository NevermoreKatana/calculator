# 02. Активность воды

## 1. Физический смысл

Активность воды — это **относительная летучесть воды** в продукте:

```
a_w = p / p₀
```

где `p` — парциальное давление паров воды над продуктом, `p₀` — над чистой
водой при той же температуре.

Термодинамически a_w — это активность воды как компонента раствора, то есть
мера её **химического потенциала**:

```
μ_w = μ_w° + R·T·ln(a_w)
```

Отсюда следуют два практических вывода:

1. Вода **самопроизвольно движется** от высокой a_w к низкой. Это и есть
   миграция влаги между слоями конфеты.
2. Микроорганизм должен затратить осмотическую работу, чтобы извлечь воду из
   среды с низкой a_w. Ниже определённого значения работа становится
   непосильной, и рост прекращается.

## 2. Связь с ERH

```
ERH (%) = a_w × 100
```

Тождество, но **только в равновесии** продукта с непосредственно окружающим
воздухом при одинаковой температуре.

Что это НЕ означает:

- что влажность склада равна a_w продукта. Их выравнивание — это и есть процесс
  миграции влаги, который продукт изменяет;
- что соотношение сохраняется при градиенте температуры. Холодная поверхность
  конденсирует влагу при той же a_w — отсюда «потение» конфет при переносе из
  холодильника.

## 3. Почему влажность ≠ активность воды

Центральное различие всего проекта.

**Влажность** — сколько воды в продукте (масса/масса).
**Активность воды** — насколько эта вода доступна.

Два продукта с одинаковой влажностью 18 % имеют разную a_w, если различаются:

| Фактор | Как влияет |
|---|---|
| **Количество растворённых веществ** | Больше растворённых частиц → ниже a_w (коллигативный эффект) |
| **Вид растворённых веществ** | Решает **мольная**, а не массовая концентрация. 1 г инвертного сахара даёт вдвое больше частиц, чем 1 г сахарозы |
| **Соли** | Диссоциируют: 1 моль NaCl даёт 2 моля частиц |
| **Белки и полисахариды** | Связывают воду сорбционно, а не осмотически. Эффект второго порядка, но реальный |
| **Жир** | Не растворяет воду и не растворяется в ней. **Разбавляет продукт, но не водную фазу** |
| **Температура** | Слабо влияет на a_w растворов, сильнее — на сорбционные системы |
| **pH** | Прямого влияния практически нет; влияет на микробиологию, а не на a_w |

### 3.1 Жир: главная ловушка расчёта

Ганаш с 40 % жира и 18 % воды имеет ту же a_w, что и его водная фаза **без
жира**. Жир — дисперсная фаза, он не растворяет ничего и не растворяется.

Если включить жир в мольный баланс, расчётная a_w окажется **завышенной** —
опасное направление ошибки для инструмента пищевой безопасности. Поэтому модель
проекта считает a_w **по водной фазе**, а жир, какао-частицы и белок выносит в
отдельную категорию «нерастворимые сухие вещества».

## 5. Модель, реализованная в проекте

### 5.1 Уравнение

Мультисолютная форма Норриша:

```
a_w = X_w · exp(−Σ_i K_i · X_i²)
```

Мольные доли берутся **по водной фазе**: вода плюс все растворённые вещества.
Жир, какао-частицы, белок и клетчатка в баланс не входят.

### 5.2 Почему именно Норриш

| Критерий | Норриш | Рауль | Ross | GAB / изотермы |
|---|---|---|---|---|
| Создано для кондитерских сиропов | **Да** | Нет | Нет | Нет |
| Учитывает неидеальность | **Да** | Нет | Частично | н/п |
| Работает при высокой концентрации | **До 90 % для сахарозы** | Нет | Хуже | н/п |
| Требует лабораторных констант продукта | **Нет** | Нет | Нет | **Да** |
| Различает виды сахаров | **Да** | Только по молям | Да | Нет |
| Применимо к ганашу | **Да, к водной фазе** | Завышает | Как проверка | **Нет** (см. 03) |

### 5.3 Валидация (ТЗ §40)

Реализация проверена против опубликованной таблицы BC Centre for Disease
Control (Food Safety Bulletin 03/97), ссылающейся на *Principles of Food
Science Part II*, с. 250.

| Сахароза, г / 100 г воды | Опубликовано | Наш расчёт | Δ |
|---|---|---|---|
| 40 | 0.969 | 0.9767 | +0.0077 |
| 60 | 0.955 | 0.9635 | +0.0085 |
| 80 | 0.941 | 0.9495 | +0.0085 |
| 100 | 0.927 | 0.9348 | +0.0078 |
| 120 | 0.913 | 0.9194 | +0.0064 |
| 140 | 0.900 | 0.9034 | +0.0034 |
| 160 | 0.888 | 0.8870 | −0.0010 |
| 180 | 0.876 | 0.8703 | −0.0057 |
| 200 | 0.860 | 0.8532 | −0.0068 |

**Максимальное отклонение 0.0085.** Это в пределах точности, которую сами
источники заявляют для композиционных моделей (±0.01).

**Найденная ошибка источника.** Строка «20 г сахарозы» напечатана как
a_w = 0.998, тогда как **собственная формула бюллетеня** `a = 1/(1 + 0.27n)`
даёт 0.984, а Норриш — 0.9889. Строка внутренне противоречива: это опечатка
источника. Она исключена из валидации, и факт закреплён отдельным тестом,
чтобы не потеряться.

### 5.4 Что модель НЕ учитывает

- связывание воды белками молока и какао-частицами (эффект оценивается в
  0.01–0.03 a_w по литературе о казеине);
- температурную зависимость констант K;
- изменение a_w при хранении (ВНИИЗ показывает, что оно реально);
- неоднородность распределения влаги внутри продукта.

Каждое ограничение отражено в ширине доверительного интервала и в списке
`limitations` результата.

## 6. Приоритет измерения

Измеренное значение a_w **всегда** имеет приоритет над расчётным (ТЗ §51).
Цепочка моделей: `измерено → справочное измерение → расчёт по составу`.
Источник значения показывается всегда.
