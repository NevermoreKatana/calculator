# 03. Изотермы сорбции влаги

## 1. Что это такое

Изотерма сорбции — зависимость равновесного влагосодержания материала от a_w
при постоянной температуре:

```
m = f(a_w)  при T = const
```

Классически выделяют три зоны:

| Зона | a_w | Состояние воды | Реакционная способность |
|---|---|---|---|
| I | < 0.2–0.3 | Прочно связанная (монослой) | Практически нереактивна |
| II | 0.3–0.7 | Слабо связанная (мультислой) | Умеренная |
| III | > 0.7 | Свободная, капиллярная и растворяющая | Полная |

Французская традиция называет их *eau liée*, *eau faiblement liée*, *eau libre*
(см. 11).

## 2. Рассмотренные модели

| Модель | Форма | Параметры | Диапазон a_w | Для чего создана |
|---|---|---|---|---|
| **BET** | `m = m₀·C·a_w / [(1−a_w)(1−a_w+C·a_w)]` | m₀, C | 0.05–0.45 | Определение монослоя |
| **GAB** | `m = m₀·C·K·a_w / [(1−K·a_w)(1−K·a_w+C·K·a_w)]` | m₀, C, K | 0.05–0.90 | Универсальная для пищевых продуктов |
| **Henderson** | `1 − a_w = exp(−k·m^n)` | k, n | широкий | Зерно |
| **Oswin** | `m = k·[a_w/(1−a_w)]^n` | k, n | широкий | Эмпирическая |
| **Halsey** | `a_w = exp(−k/m^n)` | k, n | широкий | Эмпирическая |
| **Smith** | `m = a − b·ln(1−a_w)` | a, b | 0.5–0.95 | Биополимеры |
| **Peleg** | `m = k₁·a_w^n₁ + k₂·a_w^n₂` | 4 параметра | широкий | Гибкая эмпирическая |

## 3. Вывод: к ганашу не применимы

Это **принципиальное**, а не осторожное решение. Три независимые причины.

### 3.1 Ганаш не является сорбирующей матрицей

Изотермы сорбции описывают **адсорбцию воды на сухом материале**: порошок,
сухарь, крахмал, сухофрукт. Вода там садится на поверхность и в поры.

В ганаше вода — **растворитель**, а не адсорбат. Водная фаза ганаша — это
концентрированный сахарный сироп. Физика совершенно другая: не адсорбция, а
коллигативное понижение активности растворёнными веществами. Применять к нему
изотерму сорбции — категориальная ошибка.

### 3.2 Параметры не выводятся из рецептуры

`m₀`, `C`, `K` (GAB) и все параметры остальных моделей **определяются
экспериментально для каждого материала**. Их нельзя вычислить из состава.

Для ганаша опубликованных изотерм не найдено. Подставить чужие параметры —
значит выдать чужой материал за наш.

### 3.3 Диапазон BET вдвое ниже рабочего

BET валиден при a_w 0.05–0.45. Реальная a_w ганаша — 0.70–0.90. Модель просто
не покрывает интересующий диапазон.

## 4. Где изотермы всё-таки релевантны

Отвергнуто применение **к ганашу как целому**, но не вообще:

1. **Сухие компоненты.** Какао-порошок, сухое молоко, ореховая мука — для них
   изотермы сорбции корректны и полезны при расчёте влагопоглощения при
   хранении сырья.

2. **Миграция влаги через шоколадную оболочку.** Шоколад — жиро-непрерывная
   матрица с диспергированными сахарными и какао-частицами. Его
   влагопроницаемость описывается диффузионно, и изотерма сорбции шоколада —
   часть этой задачи.

3. **Пралине и сухие начинки.** Продукты с низкой влажностью, где вода
   действительно сорбирована, а не растворяет.

Поэтому модели зарегистрированы в реестре формул со статусом
`researched_not_applicable`, а не удалены: если проект будет расширяться на
пралине и сухие изделия, обоснование уже проведено.

## 5. Что заменяет изотерму в нашей модели

Связь `влагосодержание ↔ a_w` для ганаша даёт не изотерма, а **состав водной
фазы**:

```
вода + растворённые вещества → мольные доли → уравнение Норриша → a_w
```

Это физически корректный путь для растворов и он не требует лабораторной
калибровки материала.
