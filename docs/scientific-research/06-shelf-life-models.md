# 06. Модели срока годности

## 1. Главный результат: формулы не существует

Наиболее важный вывод всего исследования.

Рецензируемый обзор по ганашу (Lapčíková et al. 2024, Foods) **не приводит ни
одной математической модели прогнозирования срока годности**. Это не пробел
нашего поиска — это состояние области.

Формула вида

```
срок годности = f(вода %, сахар %)
```

**не существует в научной литературе** и не может существовать как
универсальный закон, потому что одинаковые «20 % воды, 30 % сахара» дают:

- разную a_w при разном составе сахаров (см. 04: разброс 0.808–0.915);
- разный срок при разной упаковке, температуре, гигиене и оболочке.

## 2. Рассмотренные методы

| Метод | Что моделирует | Нужны данные | Применимо к ганашу |
|---|---|---|---|
| **Arrhenius** | Химическую порчу через T | E_a из испытаний при ≥3 T | ❌ без калибровки |
| **Q10** | То же, упрощённо | Испытания при ≥2 T | ❌ без калибровки |
| **Гамма-концепция** | Скорость роста через барьеры | Кардинальные параметры организма в матрице | ⚠️ качественно |
| **Gompertz / Baranyi** | Кривую роста популяции | μ_max, лаг-фаза для матрицы | ❌ нет параметров |
| **Growth/no growth** | Границу роста во времени | Логистическая регрессия по экспериментам | ⚠️ есть для *Z. rouxii*, но на модельной среде |
| **Weibull** | Распределение времени отказа | Данные реальных испытаний | ❌ нет данных |
| **ASLT** | Ускоренные испытания | Собственные испытания | ✅ но это измерение, а не расчёт |

## 3. Arrhenius: почему не применяем

```
k = A · exp(−E_a / (R·T))
```

Три независимые причины, любой из которых достаточно.

1. **E_a специфична для реакции и продукта.** Для ганаша не опубликована.
   Взять значение из литературы по другому изделию — значит получить
   произвольный результат с видом научного.

2. **Модель ломается там, где меняется a_w или происходит фазовый переход.**
   Литература по ASLT указывает это прямо. Исследование ВНИИЗ показывает, что
   **a_w ганаша при хранении не постоянна**. То есть условие применимости
   Аррениуса в нашем продукте нарушается систематически.

3. **Для ганаша лимитирующий фактор чаще микробиологический**, а рост
   микроорганизмов Аррениусу не подчиняется.

Модель зарегистрирована как `available_needs_data`: структура заложена, число
не выдаётся.

## 4. Q10: почему не применяем

Для пищевых продуктов Q10 обычно 2–3. Диапазон выглядит узким, но подстановка
Q10 = 2 вместо Q10 = 3 меняет расчётный срок при сдвиге на 10 °C **в полтора
раза**. Выдавать такой результат за расчёт нельзя. Q10 для ганаша не
опубликован.

## 5. Гамма-концепция: применяем качественно

```
μ = μ_opt · γ(T) · γ(pH) · γ(a_w) · γ(прочие)
```

**Структура верна и используется** — приложение показывает вклад каждого
барьера. **Численно не инстанцируется**, потому что кардинальные параметры
(T_min, pH_min, a_w,min, μ_opt) для организмов порчи ганаша **в жировой
матрице** не опубликованы. Параметры из модельной среды дали бы μ в 1/ч,
который выглядит авторитетно и не значит ничего.

## 6. Что делает приложение

### 6.1 Эмпирические контрольные точки

Три наблюдения пользователя сохранены дословно как **наблюдения**, а не закон:

| Вода | Сахара | Срок, суток |
|---|---|---|
| 17.5 % | 35 % | 90 |
| 18.6 % | 32 % | 58–63 |
| 20.0 % | 30–32 % | 38–44 |

Оценка выдаётся **только внутри наблюдённого диапазона** (вода 17.5–20 %),
одномерной интерполяцией по воде с проверкой согласованности сахаров.
За пределами — отказ, без экстраполяции.

### 6.2 Новое: точки объяснены через a_w (ТЗ §20)

ТЗ просило проверить, объяснимы ли контрольные точки через a_w, сухие вещества,
осмотическое давление. **Проверено — объяснимы.**

| Вода | Сахара | Раств. сухие в-ва водной фазы | a_w (Норриш, как сахароза) | Срок |
|---|---|---|---|---|
| 17.5 % | 35 % | **66.7 %** | **0.853** | 90 сут |
| 18.6 % | 32 % | **63.2 %** | **0.877** | 58–63 сут |
| 20.0 % | 30 % | **60.0 %** | **0.895** | 38–44 сут |
| 20.0 % | 32 % | 61.5 % | 0.887 | 38–44 сут |

**Зависимость монотонна:** чем выше a_w, тем короче срок. Это закреплено
исполняемым тестом (`§20 empirical reference points explained through a_w`).

Более того, результат согласуется с независимой литературой:

- порог **65 °Brix** из обзора по ганашу приходится ровно между точкой 1
  (66.7 %, 90 суток) и точкой 2 (63.2 %, 60 суток);
- точка 1 даёт a_w = 0.853, что практически совпадает с регуляторным порогом
  FDA 0.85;
- точка 3 даёт a_w = 0.895 — область, где обзор по ганашу описывает срок
  «менее двух недель» для незащищённых образцов, а наблюдение даёт 38–44 суток,
  что разумно для продукта в оболочке и упаковке.

**Что это означает и чего не означает.** Это означает, что наблюдения
пользователя **физически осмысленны** и объясняются активностью воды.
Это **не** означает, что теперь есть формула `a_w → дни`: для неё нужны данные
по многим рецептурам, температурам и упаковкам.

### 6.3 Разделение стабильности и срока (ТЗ §50)

```
Теоретическая стабильность          Подтверждённый срок годности
─────────────────────────           ────────────────────────────
рассчитывается из состава            только реальные испытания
показывает отсутствие барьеров       микробиология + органолептика
не является гарантией                является основанием для маркировки
```

Приложение никогда не подменяет второе первым.

## 7. Дорога к настоящей модели

Архитектура готова принять экспериментальные данные (ТЗ §38). Чтобы получить
калиброванную модель, нужно накопить по каждой партии:

- рецептуру и рассчитанный состав;
- **измеренную** a_w, pH, влажность, °Brix;
- температуру и тип упаковки;
- микробиологию по срокам;
- органолептику по срокам;
- фактический срок до отказа.

При 20–30 таких записей станет возможной интерпретируемая регрессия
`срок = f(a_w, T, упаковка)`. Машинное обучение здесь не нужно и вредно:
интерпретируемость важнее (ТЗ §38).
