# 07. Наука о ганаше

## 1. Ганаш как физическая система

Ганаш — **эмульсия масло-в-воде (O/W)** (Lapčíková et al. 2024).

| Фаза | Что входит | Роль |
|---|---|---|
| Водная (непрерывная) | Вода сливок, растворённые сахара, лактоза, соли, кислоты | **Определяет a_w** |
| Жировая (дисперсная) | Масло какао, молочный жир, сливочное масло | Текстура, не участвует в a_w |
| Твёрдые частицы | Какао-частицы, сахар сверх насыщения, кристаллы лактозы | Стабилизация эмульсии |
| Межфазный слой | Казеин, лецитин, какао-частицы | Кинетическая стабильность |

Механизм стабилизации по обзору:

- казеин водной фазы сливок способствует образованию O/W-эмульсии;
- какао-частицы мигрируют на границу раздела и стабилизируют её;
- после кристаллизации жировые кристаллы образуют мостики между каплями
  (частичная коалесценция);
- обезжиренные какао-частицы набухают остаточной свободной водой, дополнительно
  стабилизируя систему.

Последний пункт важен для нашей модели: он означает, что какао-частицы
**связывают часть воды**, а значит реальная a_w может быть **ниже** расчётной.
Направление ошибки консервативное, но величина неизвестна — это записано в
ограничениях.

## 2. Типичный состав

Из обзора и из импортированной базы:

| Параметр | Типично |
|---|---|
| Соотношение шоколад : сливки | 2:1 (тёмный), 2.5:1–3:1 (молочный/белый) |
| Доля сливок | 9–41 % масс. |
| Вода | 15–22 % |
| Сахара | 28–40 % |
| Общий жир | 25–35 % (ориентир исходного Excel: 28–32 %) |
| Сухие вещества | 78–85 % |
| a_w | 0.70–0.90 |

## 3. Активность воды ганаша: измеренные значения

| Источник | Условия | a_w |
|---|---|---|
| Izzreen et al. (в обзоре) | Белый ганаш с гидроколлоидами | **0.70–0.74** |
| Dias et al. (в обзоре) | Начинка с растрескиванием | **>0.80** |
| Van der Veken (в обзоре) | Срок < 2 недель | **>0.85** |
| Отраслевые данные | Тёмный ганаш обычный | ≈0.86 |
| Обзор | Пралине при испытании растрескивания | 0.78 / 0.86 / 0.99 |

**Целевой диапазон отрасли для длительного хранения: a_w 0.70–0.78.**

Порог из обзора: при содержании сахара выше **65 °Brix** рост микроорганизмов
подавляется при a_w около 0.70–0.74 и комнатном хранении.

## 4. Растрескивание шоколадной оболочки

Механизм по обзору: трещины возникают либо из-за **миграции влаги или этанола
через оболочку**, либо из-за неравномерного распределения влаги внутри
начинки — часть ганаша сжимается, часть расширяется.

Экспериментальный результат: пралине с начинкой a_w **0.99 трескались первыми и
чаще**, чем с a_w 0.86 и 0.78. Круглые пралине трескались раньше квадратных при
одинаковой a_w.

**Вывод для модели:** шоколадная оболочка — **частичный**, а не полный барьер.
Она замедляет обмен влагой, но вода и этанол сквозь неё проходят. Приложение
никогда не отмечает оболочку как «барьер работает».

## 5. Миграция влаги

Направление задаётся **градиентом a_w**, а не градиентом влажности:

```
высокая a_w  ────────►  низкая a_w
начинка (0.85)          шоколад (0.40)
```

Следствия:

1. Ганаш **отдаёт** влагу оболочке. Оболочка размягчается, ганаш подсыхает.
2. Многослойная конфета (фруктовое желе + ганаш + оболочка) выравнивается по
   a_w во времени. Слои, стабильные по отдельности, после выравнивания могут
   оказаться нестабильны.
3. Продукт, стабильный при изготовлении, **меняется при хранении**.
   Исследование ВНИИЗ подтверждает это прямым измерением: за 4 месяца a_w
   фруктово-ягодных начинок снижалась, а кремов — росла.

**Количественно не моделируется.** Требует коэффициента диффузии воды через
конкретный шоколад, толщины оболочки и времени. Коэффициенты измеряются, а не
берутся из литературы.

## 6. Роль ингредиентов

### Сливки
Водная фаза плюс жир плюс казеин. Сливки 35 % жира: ≈57 % воды, ≈3 % лактозы,
≈2 % белка. Лактоза осмотически активна, но **плохо растворима** — в
концентрированной водной фазе большая её часть кристаллична.

### Шоколад
Вносит сахарозу, масло какао, какао-частицы и (для молочного/белого) молочные
сухие вещества. Практически безводен, поэтому **концентрирует** водную фазу.

### Сливочное масло
Жир и небольшое количество воды. Влияет на текстуру; на a_w — через воду.

### Инвертный сахар и глюкозный сироп
Главные инструменты управления a_w. Их эффект количественно разобран в 04.
Французская практика: 8–10 % инвертного сахара или глюкозы (уровень C, как
гипотеза).

### Сорбит
Сильный понизитель a_w при низкой сладости. Осторожно: выше 60 % концентрации
водной фазы константа Норриша для сорбита теряет точность.

### Спирт
Один из немногих барьеров, действующих на *Z. rouxii*. В моделях Vermeulen
влияние этанола было наиболее выражено **в первые 30 суток**.

### Фруктовое пюре
Вносит воду, кислоту и сахара с преобладанием моносахаридов. Понижает pH — что
помогает против бактерий, но **не против осмофильных дрожжей**.

## 7. Почему модель считает по водной фазе

Ключевое архитектурное решение, повторённое здесь ради ясности.

Ганаш с 40 % жира и 18 % воды имеет **ту же a_w, что и его водная фаза без
жира**. Жир — дисперсная фаза: не растворяет и не растворяется.

Если включить жир в мольный баланс, расчётная a_w окажется завышенной, то есть
продукт будет выглядеть **менее стабильным, чем он есть** — а при обратной
ошибке (занижение) он выглядел бы **более стабильным, чем есть**, что для
инструмента пищевой безопасности недопустимо.

Поэтому:

```
a_w = f(вода, растворённые вещества)
    ≠ f(вода, все сухие вещества)
```

## 8. Практические выводы модели

1. **Целевая a_w 0.70–0.78** для длительного хранения при комнатной температуре.
2. **Состав сахаров важнее их количества.** Замена части сахарозы инвертным
   сахаром понижает a_w сильнее, чем увеличение общего количества сахарозы.
3. **Сироп DE 40 — слабый понизитель a_w.** Его роль — против кристаллизации.
4. **Подкисление не защищает от главного организма порчи** (осмофильные дрожжи).
5. **Сорбат в ганаше почти не работает**: при pH 6–7 недиссоциировано 1–5 %.
6. **Оболочка не заменяет барьер по a_w.**
7. **Расчёт описывает момент изготовления**, а не весь срок хранения.
