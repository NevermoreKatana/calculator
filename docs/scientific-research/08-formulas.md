# 08. Формулы: выбор, сравнение, соглашения

Машинно-читаемый реестр — `src/lib/science/formulas.ts`.
Автогенерируемая полная выкладка — [FORMULA-INVENTORY.md](FORMULA-INVENTORY.md)
(`npm run docs:formulas`). Здесь — рассуждение, почему выбрано именно это.

## 1. Соглашение о знаке (читать до всего остального)

Литература печатает уравнение Норриша в двух алгебраически тождественных видах:

```
a_w = X_w · exp(−K · X_s²)     K положительна   (сахароза K = +6.47)
a_w = X_w · exp(+K · X_s²)     K отрицательна   (сахароза K = −6.47)
```

**Проект использует первый вид. Все K положительны.**

Это не педантизм: смешение двух соглашений даёт a_w **больше единицы**, что
физически невозможно и при этом не всегда очевидно в выдаче. Соглашение
зафиксировано в комментарии `constants.ts` и **проверяется тестом**, который
прогоняет все виды сахаров при пяти концентрациях и требует `0 < a_w ≤ 1`.

Именно из-за этих двух соглашений в источниках выглядят противоречиво:
Chirife публикует для глюкозы «−2.25», FAO — «2.25». Это одно и то же число.

## 2. Сравнение моделей a_w (ТЗ §37)

| Модель | Область | Входные данные | Точность | T | Влажность | Применимость к ганашу |
|---|---|---|---|---|---|---|
| **Норриш (мультисолютный)** | Кондитерские сиропы | Моли и K каждого вещества | ±0.01 (наша валидация 0.0085) | 20–25 °C | до 90 % раств. в-в | ✅ **Выбрана** |
| Ross | Продукты промежуточной влажности | То же | ±0.01 (разбавл.), хуже для концентр. | — | умеренная | ✅ Как перекрёстная проверка |

| Money–Born | Кондитерские сиропы | Эквивалентная M сиропа | не проверялась нами | — | — | ⚙️ Идея M_n заимствована |

### Почему Норриш

1. **Происхождение.** Норриш (1966) вывел уравнение **для кондитерских
   сиропов**. Водная фаза ганаша и есть концентрированный кондитерский сироп.
2. **Не требует лабораторных констант продукта.** Нужны только константы
   веществ, которые опубликованы, — в отличие от GAB, где параметры измеряются
   для каждого материала.
3. **Различает виды сахаров.** Через молярную массу и через K. Это то, что
   требует ТЗ §11.
4. **Есть мультисолютная форма**, опубликованная FAO для смешанных систем.
5. **Проверяема.** Мы её проверили — см. §3.

### Почему не альтернативы

- **Рауль** систематически завышает a_w: игнорирует неидеальность. Для 67 %
  сахарозы ошибка +0.045 — это разница между «стабильно» и «нет».
- **Ross** годится, но для концентрированных смесей систематически завышает
  понижение. Используется как **второе мнение**: расхождение с Норришем идёт
  в ширину доверительного интервала.
- **Grover** — коэффициенты 1947 года для карамели и помадки, изделий **без
  жировой фазы**. Идея «сахарозного эквивалента» ценна концептуально (она же
  во французской практике «équivalent saccharose»), но уравнение Норриша даёт
  то же самое на явной физической основе.
- **Изотермы сорбции** — разобрано в [03](03-moisture-sorption.md).

## 3. Валидация (ТЗ §40)

### 3.1 Что сравнивали

Источник: BC Centre for Disease Control, Food Safety Bulletin 03/97,
ссылается на *Principles of Food Science Part II*, с. 250.

Наш расчёт: `sucroseSolutionWaterActivity(г сахарозы, 100 г воды)`,
уравнение Норриша, K = 6.47.

### 3.3 Найденная ошибка в опубликованном источнике

Строка «20 г» напечатана как **0.998**. Но **собственная формула бюллетеня**
`a = 1/(1 + 0.27n)`, где n = моли сахарозы на 100 г воды, даёт при n = 20/342
значение **0.984**. Норриш даёт 0.9889.

Строка противоречит собственной формуле источника более чем на шаг округления.
**Это опечатка публикации** (вероятно, транспозиция 0.984 → 0.998).

Строка исключена из проверки точности и закреплена **отдельным тестом**
(`documents the typo found in the published table`), чтобы находка не потерялась
при рефакторинге. ТЗ §40 требует не скрывать расхождения — здесь расхождение
оказалось в источнике, а не у нас.

### 3.4 Дополнительные проверки

| Свойство | Проверка |
|---|---|
| Монотонность | Добавление растворённого вещества всегда понижает a_w |
| Границы | `0 < a_w ≤ 1` для всех веществ при всех концентрациях |
| Согласованность форм | Однокомпонентный Норриш = мультисолютный с одним членом |
| Согласие Ross/Норриш | Расхождение < 0.02 на смешанной фазе |
| Рауль сверху | Рауль всегда даёт a_w выше Норриша |
| Отсутствие NaN | Деление на ноль возвращает NaN, а не «правдоподобное» число |
| Сохранение массы | Разложение сахаров по видам сохраняет массу до 9 знаков |
| DE-соотношение | `M_n = 18015.6/DE` выводится из молярной массы глюкозы, не зашито |

## 4. Проверка размерностей (ТЗ §39)

| Величина | Единицы | Где проверяется |
|---|---|---|
| Масса ингредиента | г | вход |
| Молярная масса | г/моль | `MOLAR_MASS` |
| Моли | моль = г / (г/моль) | `aqueous-phase.ts` |
| Мольная доля | безразмерная | отношение молей |
| K Норриша | безразмерная | `NORRISH_CONSTANTS` |
| a_w | безразмерная, 0–1 | результат |
| ERH | % = a_w × 100 | `waterActivityToERH` |
| Концентрация водной фазы | % масс. | `dissolvedSolidsPercent` |
| Растворимость | % масс. раствора | `sucroseSolubilityPercent` |
| Температура | °C | явно в имени поля |
| pH, pKa | безразмерные | `undissociatedFraction` |

**Проценты никогда не попадают в мольный баланс.** Состав ингредиентов
хранится в процентах, но в граммы переводится до входа в физическую модель.

## 5. Формула, которой нет

```
срок годности = f(вода %, сахар %)
```

Зарегистрирована в реестре со статусом `not_recommended` и
`researched_not_applicable` — не потому что мы её не нашли, а потому что
**её нет в литературе**, и рецензируемый обзор по ганашу 2024 г. это
подтверждает. Запись существует, чтобы вопрос «а почему вы её не используете?»
имел документированный ответ.
