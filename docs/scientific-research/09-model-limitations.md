# 09. Ограничения модели

Документ перечисляет всё, чего модель не делает, не может и не должна делать.
Он существует, потому что ТЗ §59 ставит честность выше полноты.

## 1. Ограничения расчёта a_w

### 1.1 Связывание воды белками и частицами — не моделируется

Казеин молока, белки какао и какао-частицы связывают воду **сорбционно**, а не
осмотически. Уравнение Норриша этого не описывает.

Литература по системам с казеином оценивает вклад в **0.01–0.028 a_w**.
Направление известно: реальная a_w **ниже** расчётной. Величина для ганаша не
измерена.

**Следствие:** расчёт консервативен (пессимистичен). Это допустимое направление
ошибки, но оно означает, что модель может недооценить стабильность хорошо
составленного ганаша.

### 1.2 Температурная зависимость — не моделируется

Константы Норриша приведены для 20–25 °C. Температурная зависимость a_w
растворов слабая, но не нулевая. Температура **учитывается** только в расчёте
растворимости сахарозы.

### 1.3 Константа для глюкозного сиропа — допущение

Опубликованной константы Норриша для «глюкозного сиропа» не существует: это
смесь переменного состава. Глюкоза (2.25) и мальтоза (4.54) её ограничивают.

Принята константа **глюкозы** — **консервативный** выбор: он занижает
понижение a_w, то есть не льстит стабильности рецептуры. Сиропы с высокой долей
мальтозы в действительности понижают a_w сильнее расчёта.

### 1.4 «Прочие сухие вещества» считаются нерастворимыми

Колонка `otherSolids` импортированной базы смешивает растворимое (кислоты,
соли, сухие вещества спиртов) и нерастворимое (клетчатка, пектин, ореховые
частицы). Без разделения всё считается нерастворимым.

**Следствие:** занижение осмотической силы, то есть **завышение** расчётной a_w.
Направление противоположно п. 1.1, и они частично компенсируют друг друга —
но не контролируемо.

### 1.5 Лактоза молочных сухих веществ по умолчанию не учитывается

Молочные сухие обезжиренные — примерно 54 % лактозы. Учтена ли эта лактоза уже
в колонке «сахара» импортированной базы, из источника **не следует
однозначно**.

Чтобы не задваивать, по умолчанию `milkSolidsLactoseFraction = 0`. Параметр
вынесен в опции: при уточнении исходных данных значение 0.54 включается одной
строкой.

### 1.6 Мультисолютная аддитивность — приближение

`Σ K_i·X_i²` предполагает, что растворённые вещества взаимодействуют с водой,
но не друг с другом. Для смеси сахаров допущение разумное и общепринятое, но
не точное. Расхождение с уравнением Росса используется как индикатор: на
реальных ганашах оно составляет 0.000–0.011.

### 1.7 Электролиты за рамками уравнения

Уравнение Норриша построено для **неэлектролитов**. Соль учитывается только
через удвоение молей (диссоциация), без коэффициентов активности Питцера.
Для ганаша, где соли мало, это приемлемо; для солёной карамели — нет.

### 1.8 Этанол учитывается только по Раулю

Для этанола принято K = 0, то есть учитывается лишь разбавляющий эффект.
Опубликованное значение K для этанола (0.91) относится к другому знаковому
соглашению и другому диапазону; вносить его без проверки было бы
некорректно.

## 2. Ограничения микробиологической модели

### 2.1 Отвечает «что может», а не «что будет»

Пересечённый порог = **отсутствие барьера**, а не прогноз порчи.
*Xeromyces bisporus* при своём пределе a_w 0.61 прорастает **120 суток**.

### 2.2 Скорость роста не рассчитывается

Гамма-концепция не инстанцирована численно: кардинальные параметры организмов
порчи ганаша **в жировой матрице** не опубликованы.

### 2.3 Исходное обсеменение неизвестно

Два одинаковых по составу ганаша с разной гигиеной производства дадут разный
фактический срок. Гигиена не рассчитывается из рецептуры в принципе.

### 2.4 Модели *Z. rouxii* получены на модельной среде

Vermeulen et al. работали в modified Sabouraud medium. Перенос на жировую
эмульсию количественно не обоснован.

## 3. Ограничения оценки срока годности

### 3.1 Формулы не существует

Установлено, а не предположено: рецензируемый обзор по ганашу не приводит ни
одной модели прогнозирования срока.

### 3.2 Контрольные точки — один продукт и один процесс

Три точки получены для конкретной рецептуры и технологии. Перенос на другую
рецептуру, оболочку или процесс не обоснован.

### 3.3 Область применимости узкая

Вода 17.5–20 %, сахара 30–35 %. Вне — отказ, без экстраполяции.

### 3.4 Три точки не задают двумерную поверхность

Точки лежат на одной монотонной траектории. Любая подогнанная плоскость была бы
произвольным выбором. Интерполяция только по воде, с проверкой согласованности
сахаров.

### 3.5 E_a и Q10 отсутствуют

Температурный пересчёт невозможен.

## 4. Ограничения по времени

**Самое недооценённое ограничение.**

Расчёт описывает **момент изготовления**. Исследование ВНИИЗ прямым измерением
показывает, что за 4 месяца хранения a_w меняется: во фруктово-ягодных начинках
снижается, в кремах растёт.

Плюс миграция влаги между слоями конфеты и через оболочку.

**Следствие:** одноразовый расчёт a_w не описывает продукт на всём сроке
хранения. Для многослойных изделий это ограничение особенно существенно.

## 5. Ограничения исходных данных

1. **64 из 113** ингредиентов описаны на сумму <99.5 %.
2. **3 ингредиента** описаны на сумму >100 % — физически невозможно
   (`fruit puree кокс capfruit` 124.3 %, `fruit puree мандарин` 106.0 %,
   `fruit puree banana` 109.0 %).
3. **Одна колонка «сахара»** — разложение по видам восстанавливается по
   названию и категории, а не измерено.
4. **Нет колонок** для pH, спирта, соли, DE, растворимой доли прочих сухих.
5. **Профиль фруктовых пюре усреднён** — реальное соотношение
   глюкоза/фруктоза/сахароза сильно зависит от вида и зрелости плода.

Данные **не нормализуются**: разница показывается как «не учтено».

## 6. Чего модель не делает принципиально

| Не делает | Почему |
|---|---|
| Не рассчитывает pH из рецептуры | Буферная ёмкость белков, кислот и щелочного какао взаимодействует нелинейно |
| Не выдаёт гарантированный срок годности | Требует реальных испытаний (ТЗ §50) |
| Не рекомендует дозировки консервантов | Регулируются законодательством конкретной страны (ТЗ §30) |
| Не моделирует миграцию влаги количественно | Нужны измеренные коэффициенты диффузии |
| Не заменяет микробиологический контроль | Ничто не заменяет |
| Не применяет изотермы сорбции к ганашу | Категориальная ошибка (см. 03) |
| Не использует машинное обучение | Интерпретируемость важнее (ТЗ §38) |

## 7. Как ограничения выражены в интерфейсе

- каждый результат несёт `Provenance`: формула, источники, статус, уверенность,
  применимость, ограничения, допущения;
- a_w выдаётся **интервалом**, а не точкой;
- уверенность падает при слабом разложении сахаров;
- нарушение области применимости — предупреждение, а не молчание;
- при недостатке данных выводится «Недостаточно данных», а не число.
